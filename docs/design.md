# 実装判断

仕様の正本: issue #1（2026-10-28 取得、コメント0件）。以下は実装時の判断です。

- `factory-scenario-1`、seed の既定値112。乱数生成は使わず、seed がプレスと移動床の初期位相を決める。物理は固定60Hz、同じ状態と入力列で再現する。
- 3つの短い横スクロール配送区間。基本足場と移動床は全ステージにあり、ステージ2からコンベア、ステージ3にゴール近接ゲートを加える。荷物は毎区間必要。
- 上面に着地する足場方式。横からの壁衝突はなく、足場下からジャンプできる。ジャンプ猶予6 tick、先行入力7 tick、ボタン解放でジャンプ高を変える。
- 地面からのジャンプは通常 -500px/s、運搬 -425px/s。水平速度245/174px/s、重力1150px/s²。コンベア+75px/s、移動床は4秒周期・振幅90px。
- プレスは通常4秒、ステージ3は3秒周期。後半1/3を危険にする。死亡はゴール成功より優先。死亡処理と翌tickの復帰を分離し、ポーズが間に入っても復帰は一回。
- チェックポイント到達前は開始地点、到達後は旗の地点へ復帰。死亡したら所持解除し、荷物も現在のチェックポイントへ復元。設置した荷物が穴に落ちても復元する。死亡で障害の位相を戻さず、初期状態リセット／再プレイでは位相も戻す。
- 保存には進行と物理・障害周期・入力エッジ状態を含める。ロード後はプレイをポーズ。保存中のUIは動作する。
- 既知バグはタイトルで個別有効化し、HUD、Observe、履歴、保存、テスト結果にIDを残す。テスト専用クリア・テレポート操作はない。モデル単体テストは内部状態を準備する境界fixtureを使い、EXE の通常操作試験とは明確に区別する。

## バグ再現条件と正常な期待結果

| ID | 再現条件 | 正常版 | 個別ON時の意図的な失敗 |
|---|---|---|---|
| B01_PLATFORM_RESPAWN | 移動床付近の穴（x510～790）へ落下して画面下を越える | 一回死亡し次tickでチェックポイントへ復帰 | 復帰予約されずsoftlock、動かない |
| B02_CARGO_LOSS | 荷物を所持してプレスまたは落下で死亡 | 所持解除、荷物はチェックポイントへ復元 | 荷物消失フラグが残り配送不能 |
| B03_DOUBLE_RESULT | 単一tickで荷物所持のゴール接触と危険判定が同時成立 | 死亡のみ、配送数は増えない | 死亡と配送の両方が記録される |

バグ注入の期待失敗は、正常版に対する同じ assertion が壊れることとして判定する。単に例外や環境エラーが出たことをバグ検出とは呼ばない。
